# Game · 安静房间

纯前端解压与小游戏合集：无构建、无后端，打开即可玩。

## 在线访问

部署后地址：

https://xgk1906806hjy.github.io/Game/

## 本地打开

```bash
python -m http.server 8765
```

浏览器访问 `http://127.0.0.1:8765/`。
